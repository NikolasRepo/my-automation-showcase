This repo is where I showcase the automation tools I use to practice and develop my skills with a heavy focus on containerization.

I use AWS to deploy Docker containers and experiment with changes on the back end and observe their effects to the front end. As I build skills and gain exposure, this document will grow to catalogue what I've accomplished and provide an overall lookback for myself to gauge my progress and direction.

'daily-checks' is my first project. The concept was an answer to a problem I saw at my day job. Repetitive, manual entries in a paper system that could be quickly and securely logged into a SQL database with digital entries. This app was my way of getting my feet wet with the an end-to-end web app, setting up Docker containers, and establishing a domain on Amazon Web Services.
